# Kuldeep Sahu — Portfolio

Personal portfolio website for [Kuldeep Sahu](https://github.com/kuldeepsahu1105), Partner Solutions Engineer at Cloudera.

**Live site:** [https://kuldeepsahu1105.github.io](https://kuldeepsahu1105.github.io)

## About

A modern, responsive portfolio built with vanilla HTML, CSS, and JavaScript. Showcases professional experience, skills, GitHub projects, and LinkedIn highlights.

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (typing effect, scroll animations, mobile nav)

## Local Development

```bash
# Clone the repo
git clone https://github.com/kuldeepsahu1105/kuldeepsahu1105.github.io.git
cd kuldeepsahu1105.github.io

# Serve locally (any static server works)
python3 -m http.server 8000
# Open http://localhost:8000
```

## Deployment

This repo is configured for [GitHub Pages](https://pages.github.com/). Push to the `main` branch and the site deploys automatically.
